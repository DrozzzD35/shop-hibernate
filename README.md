Стек: Spring Boot, Spring Web, Spring Data JPA, Hibernate, PostgreSQL, H2, Lombok.
Что сделано: Разработал полноценное REST API для веб-витрины магазина. Спроектировал реляционную структуру базы данных (PostgreSQL/H2), настроил связи между сущностями и реализовал транзакционную логику сервисов (@Transactional). Применил паттерн DTO для оптимизации передачи данных между слоями приложения.
Продвинутые фичи: Реализовал механизм мягкого удаления данных (Soft Delete через @Where), оптимистичные блокировки (@Version) для предотвращения конфликтов при параллельном доступе, настроил автоматический аудит жизненного цикла сущностей (@PrePersist, @PreUpdate) и шифрование конфиденциальных полей базы данных через AttributeConverter.
