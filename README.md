# Shop-Hibernate

Полноценное REST API для веб-витрины интернет-магазина, разработанное на фреймворке Spring Boot <!-- -->. Проект демонстрирует навыки проектирования реляционных баз данных, управления транзакциями, оптимизации передачи данных и реализации продвинутых механизмов ORM Hibernate <!-- -->.

## 🛠 Стек технологий
* **Frameworks:** Spring Boot (Spring Web, Spring Data JPA) <!-- -->
* **ORM:** Hibernate <!-- -->
* **Databases:** PostgreSQL, H2 (In-Memory DB) <!-- -->
* **Tools:** Lombok, Maven <!-- -->

## 🚀 Ключевой функционал и архитектурные решения
* **Проектирование схемы БД:** Спроектировал реляционную структуру базы данных, настроил связи между сущностями и обеспечил целостность данных <!-- -->.
* **Транзакционная логика:** Реализовал изолированную и безопасную бизнес-логику на уровне сервисного слоя с помощью аннотаций `@Transactional` <!-- -->.
* **Паттерн DTO:** Интегрировал Data Transfer Objects для оптимизации передачи данных между слоями приложения и сокрытия внутренней структуры сущностей от клиента <!-- -->.

## 🔒 Продвинутые фичи (Advanced Features)
* **Мягкое удаление (Soft Delete):** Реализовал механизм сохранения записей в БД с изменением их статуса видимости вместо физического удаления (использование аннотации `@Where`) <!-- -->.
* **Оптимистичные блокировки:** Настроил поддержку аннотации `@Version` для предотвращения конфликтов («потерянных обновлений») при параллельном конкурентном доступе к данным <!-- -->.
* **Автоматический аудит:** Настроил перехватчики жизненного цикла сущностей (`@PrePersist`, `@PreUpdate`) для автоматического ведения истории изменений <!-- -->.
* **Шифрование данных:** Реализовал кастомный класс `AttributeConverter` для прозрачного шифрования конфиденциальных полей прямо при записи в базу данных <!-- -->.
